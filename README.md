6x2x1-fonts
===========

더 구닥다리 6x2x1(영문 8x16, 한글 16x16) 조합 글꼴 ttf 변환기 & 글꼴 모음

- 한글 초성 6벌, 중성 2벌, 종성 1벌로 이루어진 조합형 글꼴. 그래서 6x2x1.
- 8비트 애플 II 시리즈에서 사용되었고, 글립의 크기는 14x16 픽셀이며,
- 애플 II의 고해상도 그래픽 모드(280x192)에서 한 화면에 한글 20자x12줄(영문 40자x12줄)을 표시할 수 있었음.
- 애플 IIe의 배밀도 고해상도 그래픽 모드(560x192)에서 화면에 40자x12줄(영문 80자x12줄)를 표시할 수 있었음.

## 조합 규칙

- 초성 6벌
  - 초성1: 종성없음. 세로 모음
  - 초성2: 종성없음. 가로 모음
  - 초성3: 종성없음. 복모음
  - 초성4: 종성있음. 세로 모음
  - 초성5: 종성있음. 가로 모음
  - 초성6: 종성있음. 복모음
- 중성 2벌
  - 중성1: 종성없음.
  - 중성2: 종성있음.
- 종성 1벌
